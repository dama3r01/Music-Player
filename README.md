# Music Player

A full-featured, offline Android music player inspired by the native music experience on Google Pixel phones.

## Features
- Discovers supported audio files on device automatically.
- Playback with ExoPlayer / Media3.
- Media controls and notifications handling.
- Compose based Modern UI.

## Requirements
- Android Device running Android 8.0 (API 26) or higher.
- Storage Permissions.
